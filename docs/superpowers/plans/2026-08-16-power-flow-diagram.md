# 電力フロー図への再設計 実装計画

## 目的

横スクロールと3タブを廃止し、太陽光 → 蓄電池 → 負荷の関係と計算結果をスマホ1画面で把握できる専用画面へ変更する。負荷の個数変更は、主画面の「負荷」ボタンから開くダイアログに集約する。

## 要件

- 主画面に太陽光、蓄電池、負荷の3ノードと、それらを結ぶ配線を大きく表示する。
- 配線には電力が流れていることを示すアニメーションを付け、`prefers-reduced-motion` では停止する。
- 負荷ノードをボタンにし、押下すると全機器の個数を調整できるモーダルを開く。
- ノード直下に、1日負荷、同時最大出力、変換損失、蓄電池入力、予備容量、必要蓄電池容量、必要太陽光出力を具体値で表示する。
- 蓄電池と太陽光の補足・価格根拠、機器の詳細入力、安全上の注意は既存機能を維持する。
- モーダルはEscape・背景・閉じるボタンで閉じ、フォーカストラップと起点へのフォーカス復帰を維持する。
- 390px幅で文書全体の横スクロールを発生させず、固定結果バーと下部ナビを表示する。

## TDD手順

1. `PowerEcosystem.test.jsx` を新UIの契約へ更新し、配線図、具体的な損失値、負荷モーダル、個数変更、補足遷移を失敗するテストとして追加する。
2. `PowerEcosystem.jsx` をフロー図と共通ダイアログ構造へ置き換え、`App.jsx` から不要なタブ状態を除去する。
3. `styles.css` でモバイル優先の配線図、通電パルス、負荷モーダル、結果内訳を実装する。
4. focused test、全テスト、build、`git diff --check` を通す。
5. 390x844 と 390x667 の実ブラウザで横スクロール、モーダル操作、値更新、アニメーション、結果バーを確認する。
